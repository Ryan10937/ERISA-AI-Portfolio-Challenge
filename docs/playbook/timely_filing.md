# Timely Filing (CO-29 style)

**CARC CO-29 definition (summary):** time limit for filing has expired.

## Workup approach
- Validate critical dates (do not assume `days_since_denial` equals submission age).
- Request proof of original submission and payer acknowledgment.
- Flag contradictions (e.g., CO-29 with very low days_since_denial) as an inconsistency and request dates.
