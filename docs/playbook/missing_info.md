# Missing / Incomplete Information (CO-16 style)

**CARC CO-16 definition (summary):** claim/service lacks information or has submission/billing errors.

## Typical first actions
1. Identify what is missing (often an EOB remark code helps).
2. Request the minimal doc set needed to resubmit:
   - itemized bill
   - operative report (if procedural)
   - clinical notes
   - authorization or referral identifiers (if applicable)

## If denial_text is sparse
If the text is just "DENIED." or empty, treat it as insufficient evidence and request:
- full EOB/ERA detail
- payer portal denial detail
- any remark codes tied to the denial
